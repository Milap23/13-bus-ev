# 13-bus-ev
Building a pipe line on 13 bus system for integration of EV in modern power system

## Run the 13-bus EV simulation

This repository now includes a runnable Python model for a radial 13-bus feeder with EV charging loads.

```bash
python /home/runner/work/13-bus-ev/13-bus-ev/simulate_13_bus_ev.py
```

The script prints:
- total active/reactive load
- estimated feeder line losses
- per-bus voltage profile (pu)
